# Git delivery

The conductor completes the agreed publication endpoint after candidate acceptance. Reuse the request's or project's existing authorization and identity binding. Decision-only work ends with its agreed decision artifacts.

Inspect the complete outgoing changes, including pre-existing commits, against the authorized scope and project branch policy. Keep unrelated work outside that publication. Complete the required commit, push or pull request to the bound repository, remote and branch.

Verify the remote ref against the intended commit; for a pull-request endpoint, verify its base and head and return its link. Record that published identity in the existing work record. Reuse valid acceptance evidence and conclude once publication is verified. If publication remains blocked, apply the conductor's authority-and-blocker handoff and distinguish accepted local work from remote delivery.
