# Point the Way

Find the best-supported workable way to achieve the user's outcome within their constraints.

1. Understand the outcome, context, and constraints. A diagnosis may help but is not required.
2. Probe uncertainty that could change the recommendation, using the least consequential useful method. Acquire suitable tools when needed. Pause before meaningful external or irreversible consequences unless authorized.
3. Compare credible approaches, including unfamiliar or creative ones. Recommend the best fit, or the highest-confidence suitable option when the user has no clear preference.
4. Explain why it should work, what must be done, and how success will be verified. Guide the user when they must act; give an implementation skill enough direction when building is required.

Do not perform production implementation without a separate request. Use supplied diagnosis as evidence and revisit it only when causal uncertainty blocks or contradicts the recommendation. If no approach is supportable, state the precise barrier and next useful probe or decision.

Use context-appropriate language and include conditions only when they affect the recommendation.
