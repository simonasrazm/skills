# ALIGN

Produce `ALIGN.md` for the same candidate named by the latest passing CHECK. When delivery falls back to an earlier proven candidate, evaluate the fallback candidate against the fallback candidate's own CHECK evidence.

Compare observed results with the original FRAME outcome, boundaries, and criterion IDs. Use FRAME and CHECK rather than MAKE claims. Record the alignment context and inputs, each criterion as `met`, `not_met`, or `blocked`, then name deviations, accidental scope, meaningful omissions, and verdict `aligned` or `repair`. Use a fresh alignment context when material judgment remains.

ALIGN passes when the selected candidate satisfies the original material outcome without adding review-time preferences.
