# FRAME

Produce `FRAME.md` before building.

Give one observable outcome, the smallest useful scope, consequential reversible assumptions, explicit boundaries, and work-product paths. FRAME each of 3–7 independently falsifiable criteria as `ID | claim | basis | proof`. Basis cites the authorizing request or specification, or explicitly derives the claim from a required outcome or boundary. Use implementation behavior to test those claims and record additional behavior as observation. For each boundary of an ordered domain, plan three probes: the boundary itself, the nearest value inside it, and the nearest value outside it, when representable. Freeze them before MAKE. Preserve later amendments with a version and reason, then recheck every affected criterion.

Resolve routine choices autonomously. Inspect the actual runtime and relevant dependency versions before choosing implementation and proof APIs. FRAME passes when another agent could build the intended result and test every criterion without guessing.
