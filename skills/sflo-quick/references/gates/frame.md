# FRAME

Produce `FRAME.md` before building.

Give one observable outcome, the smallest useful scope, consequential reversible assumptions, explicit boundaries, and work-product paths. Define 3–7 independently falsifiable criteria with stable IDs and one planned direct proof each. Freeze them before MAKE. Preserve later amendments with a version and reason, then recheck every affected criterion.

Resolve routine choices autonomously. Investigate dependencies that materially affect the outcome. FRAME passes when another agent could build the intended result and test every criterion without guessing.
