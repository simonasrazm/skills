# Perspectives

Roles are perspectives, not mandatory agents.

- **Delivery owner:** owns the outcome, artifact coherence, repair budget, and final usable result.
- **Builder:** changes the work product and records candidate identity and deltas in `MAKE.md`.
- **Verifier:** works from FRAME and the candidate in a fresh context, records direct evidence, and targets the likeliest false pass before seeing MAKE claims.
- **Scope checker:** compares FRAME with CHECK evidence, using fresh judgment when alignment is not objectively decidable.

One agent may own delivery and building. Verification still crosses a recorded context boundary: use a fresh agent, isolated model invocation, or clean execution process suited to the criterion. Objective probes need execution independence; judgment-dependent criteria need an evaluator that did not build the candidate.
