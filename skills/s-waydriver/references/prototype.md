# Prototype Decisions

A prototype is a disposable artifact built to answer one named decision question. The question determines its fidelity and proof.

Use the cheapest form that can falsify the leading options: a state model, interface variation, API spike, data sample, workflow simulation, or other concrete probe. Keep it isolated from maintained product, easy to run or inspect, and explicit about what it cannot prove.

Objective behavior may resolve autonomously from evidence. Subjective preference may be narrowed through independent critique and alternatives, but it remains human when no defensible product rule selects among them.

Retain the answer, evidence, and resulting decision; remove or clearly quarantine the throwaway mechanism. A prototype does not silently become production implementation.
