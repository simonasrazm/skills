# Autonomous Discovery

Use discovery to sharpen the destination, surface conflicts across the whole domain, and expose the first safe frontier without manufacturing questions.

Start from repository and project evidence. For each consequential unknown, state what decision it changes and assess whether evidence, current practice, specialist knowledge, or a bounded experiment can resolve it. Use `smart-shot` for substantial legwork when available; otherwise use available primary sources and bounded experiments. Preserve the resulting concepts, relationships, invariants, events, and language where they clarify the decision.

High-confidence, reversible conclusions may be accepted and recorded autonomously. Lower-confidence conclusions earn more evidence or an experiment. Ask the person one focused question only when the remaining uncertainty is consequential and the answer is genuinely their preference, authority, or unavailable knowledge.

Breadth-first charting looks across the destination before deepening one branch. Unconditional grilling is waste: stop discovering when the route is clear enough to state acceptance-bearing work. Preserve unresolved but in-scope uncertainty as fog.
